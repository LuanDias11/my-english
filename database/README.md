# Scripts SQL do My English

Esta pasta é opcional para o funcionamento do frontend. Os arquivos SQL são referências de manutenção e histórico das mudanças feitas no conteúdo do Supabase.

**Atenção:** não execute scripts em lote sem revisar os comentários, conferir o estado atual do banco e fazer backup. Estes arquivos não comprovam que o banco ativo está sincronizado com eles. A aplicação usa o Supabase configurado em `index.html`.
