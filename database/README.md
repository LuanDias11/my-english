# Banco de dados e scripts SQL — My English

Esta pasta reúne scripts de referência para manutenção e atualização do conteúdo relacionado ao My English.

## Como utilizar

- Leia cada script integralmente antes de executá-lo.
- Confira tabelas, colunas, filtros e operações afetadas.
- Compare o script com o estado atual do banco Supabase.
- Faça backup ou utilize um ambiente de teste quando apropriado.
- Execute os comandos manualmente no projeto e ambiente corretos.
- Valide o resultado antes de considerar a alteração concluída.

## Importante

Os arquivos SQL são documentação de manutenção e histórico de alterações. O frontend não os executa automaticamente, e a presença deles no GitHub **não comprova** que o banco Supabase ativo esteja sincronizado com os scripts.

A aplicação usa a configuração do Supabase definida no código. Não inclua neste repositório senhas, tokens privados ou chaves secretas. Revise também as permissões e políticas de acesso do banco antes de publicar alterações.
